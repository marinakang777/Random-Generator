## Описание

Простое десктопное приложение на Python (Tkinter) для генерации случайных задач.  
Позволяет:

- Генерировать случайную задачу из списка
- Просматривать историю всех задач
- Фильтровать задачи по типу (учеба, спорт, работа)
- Добавлять новые задачи с выбором типа
- Автоматически сохранять историю в `tasks.json`
- Очищать историю

Технологии:

*   `tkinter`: Для создания GUI.
*   `random`: Для выбора случайных задач.
*   `json`: Для сохранения и загрузки данных.
*   `os`, `datetime`: Для работы с файловой системой и датой/временем.

## Как запустить

1. Убедитесь, что установлен Python 3.6+
2. Скачайте файл `main.py`
3. Запустите:
   ```bash
   python main.py
Никаких дополнительных библиотек не требуется (Tkinter идёт в комплекте с Python).

Примеры использования
Пример 1: Генерация задачи
Запустите приложение.

Нажмите «Сгенерировать задачу».

Появится всплывающее окно с текстом задачи, например:
Ваша задача: Сделать зарядку [спорт]

Пример 2: Фильтрация
Выберите в выпадающем списке фильтр «спорт».

В списке истории останутся только спортивные задачи.

Пример 3: Добавление своей задачи
В поле «Новая задача» введите: «Помыть посуду»

Выберите тип «работа» (или любой другой)

Нажмите «Добавить задачу».

Задача появится в истории и может быть выбрана случайно.

Пример 4: Очистка истории
Нажмите «Очистить историю».

Подтвердите действие — все задачи будут удалены (файл tasks.jsonперезапишется).

Тестирование (проверка корректности)
Попытка добавить пустую задачу	Сообщение об ошибке: «Название задачи не может быть пустым»
Генерация при пустом списке задач	Предупреждение: «Добавьте хотя бы одну задачу»
Выбор фильтра «все»	Показываются все задачи из истории
Закрытие и повторный запуск	История загружается из JSON, все добавленные задачи сохраняются
Очистка истории	Список задач становится пустым, JSON перезаписан пустым массивом
